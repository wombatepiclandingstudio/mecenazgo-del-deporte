# Espana Compite Toolkit — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a self-contained browser application that lets anyone in the Spanish sports-sponsorship chain — corporate sponsor, sole trader, sports entity, individual athlete, or Foundation staff — run every fiscal and administrative calculation for the 2026 España Compite / AEIP programmes, download the resulting official paperwork as PDFs rendered with `pdfcn`, and read a Markdown playbook that lets an AI assistant drive the whole paperwork process.

**Architecture:** A static Vite + React + TypeScript SPA with three decoupled layers. Layer 1 is a pure, dependency-free TypeScript `fiscal` domain package holding every statutory constant and calculation as pure functions — the single source of truth, unit-tested in isolation with no React or DOM imports. Layer 2 is the React UI, organised as four role-scoped personas (mecenas, socio, entidad, promotor) that consume Layer 1. Layer 3 is the document layer: a `pdfcn` component tree (Takumi base) rendered inside a Web Worker, producing a PDF entirely in the browser with no server round-trip. A fourth artifact, `ASSISTANT_PLAYBOOK.md`, is the AI-assistant-facing operational manual, generated from the same constants so it cannot drift from the code.

**Tech Stack:** Vite 7 · React 19 · TypeScript 5.9 · Tailwind CSS v4 · Vitest 5 · `pdfcn` (shadcn registry, Takumi base) on `takumi-pdf` 0.18.1 + `@takumi-rs/helpers` 2.17.1 · Poppler (`pdfinfo`, `pdftotext`) + `qpdf` for PDF verification · Playwright 1.63 for browser verification.

## Global Constraints

- **Language of the product: Spanish.** All UI strings, PDF field labels and the playbook are in Spanish, because every form they reproduce is an official Fundación Deporte Joven (FDJ) document filed with the Consejo Superior de Deportes and the Agencia Tributaria. This plan and all code identifiers are in English; code comments are in English.
- **Zero server round-trips for PDF generation.** All rendering happens client-side in a Web Worker using the `takumi-pdf` WASM binary. `dist/` must contain no server runtime.
- **No hard-coded fiscal numbers outside `src/fiscal/constants.ts`.** Every percentage, cap, threshold and deadline lives in that one file with a `source` string naming the legal article. The playbook generator and the PDF generators both import from it. A grep guard (Task 13) fails the build if a fiscal literal appears anywhere else in `src/`.
- **Statutory values are pinned to fiscal year 2026 and carry their legal source inline.** The 45 % / 55 % corporate rates, the 85 % / 45 % / 50 % sole-trader scale, the 20 % base-imponible and 15 % base-liquidable ceilings, the €50,000 annual cap, the 2,75 % flat canon, the AEIP progressive canon and the advertising 15 % / 90 % ceiling come from the verified research in `docs/superpowers/plans/` and are reproduced exactly. Any value whose legal basis could change — notably the 2026 budget prorrogation — must be flagged in the UI, never silently applied.
- **`pdfcn` is vendored, not depended on.** The registry is installed with the shadcn CLI and the resulting component source is committed. The build must never fetch `pdfcn.dev` at install time.
- **The sandbox blocks `pdfcn.dev` and `ui.shadcn.com`.** Both registries must be mirrored from GitHub and served locally. `scripts/setup-registry-mirror.sh` automates this; it is a hard prerequisite for Task 7, not an optional convenience. See "Registry mirror" at the end for the exact, verified procedure.
- **No agent delegation for the fiscal engine.** Tasks 2–6 are pure functions with a fast test cycle and must be implemented and reviewed as single units. `superpowers:dispatching-parallel-agents` is explicitly out of scope for this plan.
- **Every generated PDF must pass a four-point verification gate:** `pdfinfo` reports the expected page count and A4 geometry (`595.276 x 841.89 pts`); `pdftotext` returns the expected Spanish strings with correct accents (`ñ á é í ó ú ¿ ¡ « » €`); `qpdf --check` reports no syntax or stream-encoding errors; and a Chromium render via Playwright confirms the download path works end to end.
- **Test-first.** Each task writes its failing test, confirms the failure, implements the minimum that passes, then commits. No task lands with a red suite.

```typescript
  flatCanonRate: number | null;

  allowsAdvertisingRoute: boolean;
  source: string;

export interface DonationResult {
  donationAmount: number;

  deductibleBase: number;
  /** Amount spilling into the 10-year carry-forward. */
  carriedForward: number;
  /** Effective rate over the deductible base. */
  rate: number;
  deduction: number;
  /** Which ceiling bound the deductible base, for display purposes. */
  bindingConstraint: "annual-cap" | "base-limit" | "none";
  netToProject: number;
  canonRate: number;
  canonAmount: number;
  notes: string[];
}

export interface AdvertisingResult {
  advertisingSpend: number;

  notes: string[];
}

export interface CanonResult {
```

```typescript
import { FISCAL_2026, PROGRAMMES_2026 } from "./constants";
import type { CanonResult, ProgrammeId } from "./types";

export function calculateCanon(donation: number, programme: ProgrammeId): CanonResult {
  const definition = PROGRAMMES_2026[programme];

  if (definition.flatCanonRate !== null) {
    const amount = donation * definition.flatCanonRate;
    return {
      rate: definition.flatCanonRate,
      amount,
      netToProject: donation - amount,
      bracket: "Canon plano del 2,75% (España Compite)",
    };
  }

  const brackets = FISCAL_2026.aeipCanonBrackets;
  const bracket =
    brackets.find((b) => donation <= b.upTo) ?? brackets[brackets.length - 1];

  return {
    rate: bracket.rate,
    amount: donation * bracket.rate,
    netToProject: donation - donation * bracket.rate,
    bracket: bracket.label,
  };
}
```

```typescript
  donation: number;
  baseImponible: number;
  repeatDonation: boolean;
  programme: ProgrammeId;
}

export function calculateCorporateDonation(
  input: CorporateDonationInput,
): DonationResult {
  const programme = PROGRAMMES_2026[input.programme];
  const notes: string[] = [];
  const { corporate } = FISCAL_2026;

  if (input.donation < programme.minimumDonation) {
    return {
      donationAmount: input.donation,
      deductibleBase: 0,
      carriedForward: input.donation,
      rate: 0,
      deduction: 0,

    bindingConstraint = "annual-cap";

    bindingConstraint = "base-limit";
  }

  const rate = input.repeatDonation ? corporate.donationRateRepeat : corporate.donationRate;
  const deduction = deductibleBase * rate;
  const carriedForward = input.donation - deductibleBase;

  if (bindingConstraint === "annual-cap") {

    notes.push(
      `La base deducible se recorta al 20% de la base imponible (${Math.round(baseLimit)} €) ` +
        "antes de aplicar el porcentaje.",
    );

  if (carriedForward > 0) {
    notes.push(
      `El importe no deducible ahora (${carriedForward} €) puede aplicarse en los ejercicios ` +
        `que concluyan en los ${corporate.carryForwardYears} años inmediatos y sucesivos.`,
    );
  }
  if (programme.flatCanonRate === null) {
    notes.push(
      "El canon de gestión de los programas AEIP se aplica con un tipo progresivo por tramos; " +
        "confirme el aplicable con la Fundación.",

  const canon = calculateCanon(input.donation, input.programme);

  return {
    donationAmount: input.donation,
    deductibleBase,
    carriedForward,
    rate,
    deduction,
    bindingConstraint,
    netToProject: canon.netToProject,
    canonRate: canon.rate,
```

```typescript
import type { AdvertisingResult, ProgrammeId } from "./types";

export interface AdvertisingInput {
  donation: number;
  advertisingSpend: number;
  essentialPublicity: boolean;
  programme?: ProgrammeId;
}

export function calculateAdvertising(input: AdvertisingInput): AdvertisingResult {
  const notes: string[] = [];
  const { advertising } = FISCAL_2026;

  if (input.programme && !PROGRAMMES_2026[input.programme].allowsAdvertisingRoute) {
    return {
      advertisingSpend: input.advertisingSpend,
      admissibleBase: 0,
      ceilingAmount: 0,
      deduction: 0,

          "este programa solo admite donaciones y aportaciones en especie.",
      ],
    };
  }

  const admissibleBase = input.essentialPublicity
    ? input.advertisingSpend
    : input.advertisingSpend * advertising.nonEssentialBaseRatio;

  const rawDeduction = admissibleBase * advertising.rate;
  const ceilingAmount = input.donation * advertising.ceilingRatioOfDonation;
  const bindingConstraint: AdvertisingResult["bindingConstraint"] =
    rawDeduction > ceilingAmount ? "ceiling" : "none";
  const deduction = Math.min(rawDeduction, ceilingAmount);

  if (bindingConstraint === "ceiling") {
    notes.push(

    );
  }
  if (!input.essentialPublicity) {
    notes.push(
      "La publicidad no esencial computa por el 25% del gasto, por lo que la base admisible se " +
        "reduce a la cuarta parte.",
    );
  }

    "Las donaciones a las que se aplica esta deducción publicitaria no pueden acogerse a los " +
      "demás incentivos fiscales previstos en la Ley 49/2002: las vías son excluyentes.",
  );

  return {
    advertisingSpend: input.advertisingSpend,
    admissibleBase,
    ceilingAmount,
    deduction,
    bindingConstraint,
    essentialPublicity: input.essentialPublicity,
    notes,
```

```typescript
import { DEADLINES_2026, PROGRAMMES_2026 } from "./constants";
import type { ProgrammeId, ScheduleResult } from "./types";

export interface ScheduleInput {
  programme: ProgrammeId;
  today: Date;
  donation?: number;
  plannedInstalments?: number;
}

const MONTH_INDEX: Record<string, number> = {
  enero: 0, febrero: 1, marzo: 2, abril: 3, mayo: 4, junio: 5,
  julio: 6, agosto: 7, septiembre: 8, octubre: 9, noviembre: 10, diciembre: 11,
};

const startOfDay = (d: Date) =>
  new Date(Date.UTC(d.getUTCFullYear(), d.getUTCMonth(), d.getUTCDate()));

const daysBetween = (from: Date, to: Date) =>
  Math.round((startOfDay(to).getTime() - startOfDay(from).getTime()) / 86_400_000);

export function calculateSchedule(input: ScheduleInput): ScheduleResult {
  const { today } = input;
  const programme = PROGRAMMES_2026[input.programme];
  const deadlines = DEADLINES_2026.espanaCompite;
  const blockers: string[] = [];

  const applicationDeadline = new Date(`${deadlines.applicationDeadline}T00:00:00Z`);
  const donationDeadline = new Date(`${deadlines.donationRequestDeadline}T00:00:00Z`);
  const fundsDate = new Date(`${deadlines.fundsAvailableBy}T00:00:00Z`);

  const daysUntilApplicationDeadline = daysBetween(today, applicationDeadline);
  const daysUntilDonationRequestDeadline = daysBetween(today, donationDeadline);
  const daysUntilFundsAvailable = daysBetween(today, fundsDate);

  if (daysUntilApplicationDeadline < 0) {
    blockers.push("El plazo de solicitud de ayuda venció el 04/12/2026.");
  }
  if (daysUntilFundsAvailable < 0) {
    blockers.push("La Fundación debía disponer del dinero antes del 18/12/2026.");
  }

  const currentMonth = today.getUTCMonth();
  const openInstalmentMonths = deadlines.paymentScheduleMonths.filter(
    (m) => (MONTH_INDEX[m] ?? 0) >= currentMonth,
  );

  if (input.donation !== undefined && input.plannedInstalments !== undefined) {
    if (input.donation < programme.minimumDonation) {
      blockers.push(
        `La aportación de ${input.donation} € es inferior al mínimo de ` +
          `${programme.minimumDonation} € del programa.`,
      );
    }
    if (input.plannedInstalments > openInstalmentMonths.length) {
      blockers.push(
        `Solo quedan ${openInstalmentMonths.length} meses abiertos en el calendario de pagos de ` +
          `2026 (${openInstalmentMonths.join(", ")}) y se han previsto ` +
          `${input.plannedInstalments} fracciones.`,
      );
    }
    const instalment = input.donation / input.plannedInstalments;
    if (instalment < deadlines.minimumInstalment) {
      blockers.push(
        `Cada fracción sería de ${instalment.toFixed(2)} €, por debajo del mínimo de ` +
          "1.000 € por fracción.",
      );
    }
  }

  if (DEADLINES_2026.budgetBridge.prorogued) {
    blockers.push(
      "Aviso: los PGE de 2026 no se aprobaron y los de 2023 siguen prorrogados; los porcentajes " +
        "y límites de 2026 se aplican sobre un régimen presupuestario prorrogado.",
    );
  }

  return {
    daysUntilApplicationDeadline,
    daysUntilDonationRequestDeadline,
    daysUntilFundsAvailable,
    openInstalmentMonths,
    eligible: blockers.filter((b) => !b.startsWith("Aviso:")).length === 0,
    blockers,
  };
}
```

```bash
#!/usr/bin/env bash
# Serve the pdfcn and shadcn registries from local copies, because the sandbox
# has no egress to pdfcn.dev or ui.shadcn.com.
#
# Idempotent: re-running it reuses the downloaded registry trees.
set -euo pipefail

ROOT="$(cd "$(dirname "${BASH_SOURCE[0]}")/.." && pwd)"
MIRROR="$ROOT/registry-mirror"
PORT="${MIRROR_PORT:-4788}"
WORK="$(mktemp -d)"
trap 'rm -rf "$WORK"' EXIT

mkdir -p "$MIRROR/r"

fetch_and_extract() {
  local url="$1" out="$2"
  echo "==> fetching $url"
  for attempt in 1 2 3; do
    if curl -sSL --max-time 300 -o "$WORK/repo.tgz" "$url" && [ -s "$WORK/repo.tgz" ]; then
      break
    fi
    [ "$attempt" -eq 3 ] && { echo "download failed: $url" >&2; exit 1; }
    sleep 5
  done
  tar xzf "$WORK/repo.tgz" -C "$WORK"
  local found
  found="$(find "$WORK" -type d -path "$out" | head -1)"
  [ -n "$found" ] || { echo "pattern $out not found in $url" >&2; exit 1; }
  cp -r "$found/." "$MIRROR/r/"
}

if [ ! -d "$MIRROR/.pdfcn-ok" ]; then
  fetch_and_extract \
    "https://codeload.github.com/shadcn-labs/pdfcn/tar.gz/refs/heads/main" \
    "*/apps/web/public/r"
  touch "$MIRROR/.pdfcn-ok"
fi

if [ ! -d "$MIRROR/.shadcn-ok" ]; then
  fetch_and_extract \
    "https://codeload.github.com/shadcn-ui/ui/tar.gz/refs/heads/main" \
    "*/apps/v4/public/r"
  touch "$MIRROR/.shadcn-ok"
fi

echo "==> registry contents:"
ls "$MIRROR/r"

# The shadcn CLI always fetches base colours and styles from ui.shadcn.com and
# refuses plain HTTP for that core namespace, so serve the mirror over TLS on
# 443 and point the hostname at localhost.
if ! grep -q "ui.shadcn.com" /etc/hosts; then
  echo "127.0.0.1 ui.shadcn.com" >> /etc/hosts
fi

cd "$MIRROR"
openssl req -x509 -newkey rsa:2048 -keyout key.pem -out cert.pem -days 365 -nodes \
  -subj "/CN=ui.shadcn.com" \
  -addext "subjectAltName=DNS:ui.shadcn.com,DNS:localhost,IP:127.0.0.1"

cat > server.py <<'PY'
import http.server, ssl, os
os.chdir(os.path.join(os.path.dirname(os.path.abspath(__file__)), "r"))
ctx = ssl.SSLContext(ssl.PROTOCOL_TLS_SERVER)
ctx.load_cert_chain("cert.pem", "key.pem")
httpd = http.server.HTTPServer(("127.0.0.1", 443), http.server.SimpleHTTPRequestHandler)
httpd.socket = ctx.wrap_socket(httpd.socket, server_side=True)
httpd.serve_forever()
PY

# Plain HTTP mirror for the @pdfcn namespace.
pkill -f "registry-mirror/server.py" 2>/dev/null || true
pkill -f "http.server $PORT" 2>/dev/null || true
nohup python3 server.py >"$MIRROR/server.log" 2>&1 &
nohup python3 -m http.server "$PORT" --directory "$MIRROR/r" >"$MIRROR/http.log" 2>&1 &
sleep 2

echo "==> registry mirror ready."
echo "    export NODE_EXTRA_CA_CERTS=$MIRROR/cert.pem"
echo "    npx shadcn@latest add @pdfcn/takumi/text --yes --overwrite"
```

**Worker protocol.** The main thread posts **plain JSON data only** — never a React element. React elements carry `$$typeof: Symbol.for(...)`, which the structured-clone algorithm cannot clone, so posting one throws `DataCloneError`. The worker owns the component tree: it receives a document kind plus a model, builds the element itself, and returns PDF bytes. This mirrors pdfcn's own playground, which likewise sends a payload the worker turns into an element before calling `render`.

```typescript
import { fromJsx } from "@takumi-rs/helpers/jsx";
import initPdf, { render } from "takumi-pdf/no-init";
import wasmUrl from "takumi-pdf/wasm-url";
import { createElement } from "react";
import { FormularioDonante } from "./documents/FormularioDonante";
import { FormularioSolicitante } from "./documents/FormularioSolicitante";
import { MemoriaJustificativa } from "./documents/MemoriaJustificativa";
import { CertificadoVNC } from "./documents/CertificadoVNC";
import { InformeCalculo } from "./documents/InformeCalculo";
import { InformeComparativo } from "./documents/InformeComparativo";

export type PdfDocumentKind =
  | "donante"
  | "solicitante"
  | "memoria"
  | "vnc"
  | "informe-calculo"
  | "informe-comparativo";

export interface PdfRenderRequest {
  kind: PdfDocumentKind;
  /** Plain JSON model for the document. */
  model: unknown;
}

export interface PdfRenderResponse {
  ok: boolean;
  bytes?: ArrayBuffer;
  error?: string;
}

const DOCUMENTS: Record<PdfDocumentKind, (model: never) => unknown> = {
  "donante": FormularioDonante as (model: never) => unknown,
  solicitante: FormularioSolicitante as (model: never) => unknown,
  memoria: MemoriaJustificativa as (model: never) => unknown,
  vnc: CertificadoVNC as (model: never) => unknown,
  "informe-calculo": InformeCalculo as (model: never) => unknown,
  "informe-comparativo": InformeComparativo as (model: never) => unknown,
};

let ready: Promise<unknown> | undefined;

const initWasm = () => {
  ready ??= initPdf({ module_or_path: wasmUrl });
  return ready;
};

self.onmessage = async (event: MessageEvent<PdfRenderRequest>) => {
  try {
    await initWasm();
    const component = DOCUMENTS[event.data.kind];
    const element = createElement(component as never, { model: event.data.model } as never);
    const { node, css } = await fromJsx(element);
    const bytes = await render(node, { size: "a4", css });
    const transferable = bytes.buffer.slice(0) as ArrayBuffer;
    (self as unknown as Worker).postMessage({ ok: true, bytes: transferable }, [transferable]);
  } catch (error) {
    (self as unknown as Worker).postMessage({
      ok: false,
      error: error instanceof Error ? error.message : String(error),
    });
  }
};
```

Create `src/pdf/usePdfRenderer.ts`:

```typescript
import { useCallback, useRef, useState } from "react";
import type { PdfRenderRequest, PdfRenderResponse } from "./render.worker";

export interface PdfRendererState {
  renderPdf: (request: PdfRenderRequest) => Promise<Uint8Array>;
  isRendering: boolean;
  error: string | null;
}

export function usePdfRenderer(): PdfRendererState {
  const workerRef = useRef<Worker | null>(null);
  const pendingRef = useRef(
    new Map<number, { resolve: (b: Uint8Array) => void; reject: (e: Error) => void }>(),
  );
  const [isRendering, setIsRendering] = useState(false);
  const [error, setError] = useState<string | null>(null);

  const getWorker = useCallback(() => {
    if (workerRef.current) return workerRef.current;
    const worker = new Worker(new URL("./render.worker.ts", import.meta.url), { type: "module" });
    worker.onmessage = (event: MessageEvent<PdfRenderResponse>) => {
      const { ok, bytes, error: message } = event.data;
      const entry = pendingRef.current.values().next().value;
      pendingRef.current.clear();
      if (entry) {
        if (ok && bytes) entry.resolve(new Uint8Array(bytes));
        else entry.reject(new Error(message ?? "Error de renderizado"));
      }
      setIsRendering(false);
    };
    worker.onerror = (event) => {
      setError(event.message);
      pendingRef.current.clear();
      setIsRendering(false);
    };
    workerRef.current = worker;
    return worker;
  }, []);

  const renderPdf = useCallback(
    (request: PdfRenderRequest) => {
      setIsRendering(true);
      setError(null);
      const worker = getWorker();
      return new Promise<Uint8Array>((resolve, reject) => {
        pendingRef.current.set(Date.now(), { resolve, reject });
        worker.postMessage(request);
      });
    },
    [getWorker],
  );

  return { renderPdf, isRendering, error };
}
```

**Interfaces:**
- Consumes: `calculateCorporateDonation`, `calculateSoleTraderDonation`, `calculateAdvertising`, `calculateCanon`, `calculateSchedule`, the constants, and the vendored pdfcn components.
- Produces: one React component per document, each taking `{ model }` and rendering a complete A4 page.

**Component contracts verified against the installed registry** — follow them exactly:

| Component | Props that exist | Props that do **not** exist |
|---|---|---|
| `Text` | `variant` (`xs`/`sm`/`base`/`lg`/`xl`/`2xl`/`3xl`), `align`, `color`, `weight` (`normal`/`medium`/`semibold`/`bold`), `italic`, `decoration`, `transform`, `noMargin`, `style`, `children` | `size` |
| `PageHeader` | `title` (required), `subtitle`, `rightText`, `rightSubText`, `variant`, `background`, `titleColor`, `marginBottom`, `address`, `phone`, `email`, `logo`, `fixed`, `noWrap` | — |
| `PageFooter` | `leftText`, `rightText`, `centerText`, `variant`, `background`, `textColor`, `marginTop`, `address`, `phone`, `email`, `website`, `fixed`, `sticky`, `pagePadding`, `noWrap`, `children` | `note` |
| `Section` | `spacing`, `padding`, `background`, `border`, `variant`, `accentColor`, `noWrap`, `children` | `title` |
| `Table` | `variant` (`line`/`grid`/`minimal`/`striped`/`compact`/`bordered`/`primary-header`), `zebraStripe`, `noWrap`, `children` | — |
| `TableHeader` / `TableBody` / `TableFooter` | `children`, `style` | — |
| `TableRow` | `header`, `footer`, `stripe`, `variant`, `children` | — |
| `TableCell` | `header`, `footer`, `align`, `width`, `variant`, `children` | — |
| `KeyValue` | `items: { key, value, valueColor?, valueStyle?, keyStyle? }[]`, `direction`, `divided`, `size`, `labelFlex`, `boldValue`, `noWrap` | — |

`children` is **required** on every one of these components. `Document` accepts `{ children, title, style }`; `Page` accepts `{ children, size, style }` but the primitive ignores `size` — the real page size comes from `render(node, { size: "a4" })`.

```typescript
import { Section } from "@/components/pdf/section/section";
import { Table, TableCell, TableHeader, TableRow } from "@/components/pdf/table/table";
import { Text } from "@/components/pdf/text/text";
import { DEADLINES_2026 } from "@/fiscal/constants";
import type { ProgrammeId } from "@/fiscal/types";
import { Document, Page } from "@/lib/pdf-primitives";

export interface JustificationExpense {
  date: string;
  concept: string;
  amount: number;
  vatRecoverable?: boolean;
  paidInCash?: boolean;
}

export interface JustificationInput {
  programme: ProgrammeId;
  entityName: string;
  projectTitle: string;
  expenses: JustificationExpense[];
}

export interface JustificationModel {
  title: string;
  entityName: string;
  projectTitle: string;
  expenses: JustificationExpense[];
  rejectedExpenses: { expense: JustificationExpense; reason: string }[];
  total: number;
  notes: string[];
  deadline: string;
}

const euro = (n: number) =>
  n.toLocaleString("es-ES", { minimumFractionDigits: 2, maximumFractionDigits: 2 }) + " €";

export function buildJustificationModel(input: JustificationInput): JustificationModel {
  const deadlines = DEADLINES_2026.espanaCompite;
  const accepted: JustificationExpense[] = [];
  const rejected: { expense: JustificationExpense; reason: string }[] = [];
  const notes: string[] = [];

  for (const expense of input.expenses) {
    if (
      expense.date < deadlines.eligibleExpenseWindowStart ||
      expense.date > deadlines.eligibleExpenseWindowEnd
    ) {
      rejected.push({
        expense,
        reason: "La fecha del gasto no está dentro del ejercicio 2026.",
      });
      continue;
    }
    if (expense.paidInCash && expense.amount >= deadlines.cashPaymentProhibitionThreshold) {
      rejected.push({
        expense,
        reason:
          "No se admiten pagos en efectivo por importe igual o superior a 1.000 € (art. 7 Ley 7/2012).",
      });
      continue;
    }
    if (expense.vatRecoverable) {
      notes.push(
        "El IVA recuperable no se admite como gasto: solo computa el importe sin IVA.",
      );
    }
    accepted.push(expense);
  }

  if (accepted.length > 0) {
    notes.push(
      `Los originales de los justificantes de gasto y pago deben custodiarse durante ` +
        `${deadlines.documentCustodyYears} años desde la conclusión del proyecto validado.`,
    );
  }

  return {
    title: "Memoria justificativa del proyecto",
    entityName: input.entityName,
    projectTitle: input.projectTitle,
    expenses: accepted,
    rejectedExpenses: rejected,
    total: accepted.reduce((sum, e) => sum + e.amount, 0),
    notes,
    deadline:
      `${deadlines.justificationDays} días desde la finalización del proyecto ` +
      `(${deadlines.justificationDaysIfEndingOn31December} días si termina el 31/12/2026)`,
  };
}

export function MemoriaJustificativa({ model }: { model: JustificationModel }) {
  return (
    <Document title={model.title}>
      <Page size="a4">
        <Section border>
          <Text variant="lg" weight="semibold">
            {model.title}
          </Text>
          <Text variant="sm">Entidad: {model.entityName}</Text>
          <Text variant="sm">Proyecto: {model.projectTitle}</Text>
          <Text variant="sm">Plazo de justificación: {model.deadline}</Text>
        </Section>

        <Section>
          <Text variant="lg" weight="semibold">
            Relación de justificantes de gasto y pago
          </Text>
          <Table variant="grid">
            <TableHeader>
              <TableRow>
                <TableCell header>Fecha</TableCell>
                <TableCell header>Concepto</TableCell>
                <TableCell header align="right">
                  Importe
                </TableCell>
              </TableRow>
            </TableHeader>
            {model.expenses.map((e, i) => (
              <TableRow key={`${e.date}-${i}`}>
                <TableCell>{e.date}</TableCell>
                <TableCell>{e.concept}</TableCell>
                <TableCell align="right">{euro(e.amount)}</TableCell>
              </TableRow>
            ))}
          </Table>
          <Text variant="sm" weight="semibold">
            Total justificado: {euro(model.total)}
          </Text>
        </Section>

        {model.rejectedExpenses.length > 0 && (
          <Section>
            <Text variant="lg" weight="semibold">
              Gastos no admitidos
            </Text>
            {model.rejectedExpenses.map((r, i) => (
              <Text key={i} variant="sm">
                {r.expense.concept}: {r.reason}
              </Text>
            ))}
          </Section>
        )}

        <Section>
          <Text variant="lg" weight="semibold">
            Notas
          </Text>
          {model.notes.map((n, i) => (
            <Text key={i} variant="sm">
              {n}
            </Text>
          ))}
        </Section>
      </Page>
    </Document>
  );
}
```

```typescript
import { calculateAdvertising } from "@/fiscal/advertising";
import { PROGRAMMES_2026 } from "@/fiscal/constants";
import { calculateCorporateDonation } from "@/fiscal/donation";
import { calculateSchedule } from "@/fiscal/schedule";
import { calculateSoleTraderDonation } from "@/fiscal/sole-trader";
import type { ProgrammeId } from "@/fiscal/types";
import type { ComparisonRow, MecenasView } from "./types";

export interface MecenasViewInput {
  programme: ProgrammeId;
  donorProfile: "corporate" | "sole-trader";
  donation: number;
  baseImponible: number;
  repeatDonation: boolean;
  today?: Date;
}

export function buildMecenasView(input: MecenasViewInput): MecenasView {
  const primary =
    input.donorProfile === "corporate"
      ? calculateCorporateDonation({
          donation: input.donation,
          baseImponible: input.baseImponible,
          repeatDonation: input.repeatDonation,
          programme: input.programme,
        })
      : calculateSoleTraderDonation({
          donation: input.donation,
          baseLiquidable: input.baseImponible,
          repeatDonation: input.repeatDonation,
          programme: input.programme,
        });

  const programme = PROGRAMMES_2026[input.programme];

  const comparison: ComparisonRow[] = Object.values(PROGRAMMES_2026).map((p) => ({
    programme: p.id,
    name: p.name,
    cap: p.hasAnnualCap ? "50.000 €/año" : "sin límite",
    canon: p.flatCanonRate !== null ? "2,75 % plano" : "escala progresiva",
    advertising: p.allowsAdvertisingRoute ? "sí" : "no",
  }));

  const schedule = calculateSchedule({
    programme: input.programme,
    today: input.today ?? new Date(),
  });

  return {
    primary,
    comparison,
    showsAdvertisingRoute: programme.allowsAdvertisingRoute,
    canDownloadDonorForm: input.donation >= programme.minimumDonation,
    advertising: programme.allowsAdvertisingRoute
      ? calculateAdvertising({
          donation: input.donation,
          advertisingSpend: 0,
          essentialPublicity: true,
          programme: input.programme,
        })
      : null,
    schedule,
    notes: primary.notes,
    blockers: schedule.blockers,
  };
}
```

```typescript
import { DEADLINES_2026 } from "@/fiscal/constants";
import { calculateSchedule } from "@/fiscal/schedule";
import type { ProgrammeId } from "@/fiscal/types";
import type { EntidadView } from "./types";

export interface EntidadViewInput {
  programme: ProgrammeId;
  entityName: string;
  budget: number;
  requestedAmount: number;
  hasFederationAgreement: boolean;
  hasEducationalAgreement: boolean;
  hasAthleteList: boolean;
  today?: Date;
}

const LINES = [
  { line: "competiciones", label: "Organización de competiciones" },
  { line: "preparacion", label: "Preparación y detección de talento" },
  { line: "carrera-dual", label: "Carrera dual" },
  { line: "organizacion", label: "Gestión y organización" },
] as const;

export function buildEntidadView(input: EntidadViewInput): EntidadView {
  const schedule = calculateSchedule({
    programme: input.programme,
    today: input.today ?? new Date(),
  });

  const eligibleLines = LINES.map((l) => {
    let eligible = true;
    let reason = "Sin requisitos documentales adicionales.";

    if (l.line === "competiciones" && !input.hasFederationAgreement) {
      eligible = false;
      reason = "Exige acuerdo o licencia de la federación deportiva correspondiente.";
    }
    if (l.line === "carrera-dual") {
      if (!input.hasEducationalAgreement) {
        eligible = false;
        reason = "Exige acuerdo de colaboración con un centro educativo.";
      } else if (!input.hasAthleteList) {
        eligible = false;
        reason = "Exige listado de deportistas con licencia federativa en vigor.";
      } else {
        reason = "Documentación completa: acuerdo educativo y listado de deportistas.";
      }
    }
    if (l.line === "preparacion" && !input.hasAthleteList) {
      eligible = false;
      reason = "Exige listado de deportistas con licencia federativa en vigor.";
    }

    return { line: l.line, label: l.label, eligible, reason };
  });

  return {
    eligibleLines,
    budget: input.budget,
    requestedAmount: input.requestedAmount,
    gap: Math.max(0, input.budget - input.requestedAmount),
    deadline: "04/12/2026",
    schedule,
    notes: [
      `La solicitud se presenta antes del 04/12/2026 a espanacompite@deportejoven.es.`,
      `La memoria justificativa se presenta en los ${DEADLINES_2026.espanaCompite.justificationDays} ` +
        `días siguientes a la finalización del proyecto ` +
        `(${DEADLINES_2026.espanaCompite.justificationDaysIfEndingOn31December} días si termina el 31/12/2026).`,
    ],
    blockers: schedule.blockers,
  };
}
```

```typescript
export function buildFilename(programme: string, label: string): string {
  const slug = label
    .normalize("NFD")
    .replace(/[\u0300-\u036f]/g, "")
    .replace(/[^a-zA-Z0-9]+/g, "-")
    .replace(/^-+|-+$/g, "")
    .toLowerCase();
  return `${programme}-2026-${slug.length > 0 ? slug : "donante"}.pdf`;
}

export function downloadPdf(bytes: Uint8Array, filename: string): void {
  const blob = new Blob([bytes], { type: "application/pdf" });
  const url = URL.createObjectURL(blob);
  const anchor = document.createElement("a");
  anchor.href = url;
  anchor.download = filename;
  document.body.appendChild(anchor);
  anchor.click();
  anchor.remove();
  URL.revokeObjectURL(url);
}
```

```typescript
import { useState } from "react";
import { downloadPdf } from "./download";
import { usePdfRenderer } from "./usePdfRenderer";
import type { PdfDocumentKind } from "./render.worker";

export interface DownloadButtonProps {
  label: string;
  filename: string;
  kind: PdfDocumentKind;
  model: unknown;
}

export function DownloadButton({ label, filename, kind, model }: DownloadButtonProps) {
  const { renderPdf, isRendering, error } = usePdfRenderer();
  const [status, setStatus] = useState<string | null>(null);

  return (
    <div className="space-y-1">
      <button
        disabled={isRendering}
        onClick={async () => {
          setStatus("Generando PDF…");
          try {
            const bytes = await renderPdf({ kind, model });
            downloadPdf(bytes, filename);
            setStatus("PDF descargado.");
          } catch (e) {
            setStatus(e instanceof Error ? e.message : "Error al generar el PDF.");
          }
        }}
        className="rounded bg-[#0F4C81] px-4 py-2 text-white disabled:opacity-60"
      >
        {isRendering ? "Generando…" : label}
      </button>
      {status && <p className="text-xs text-[#5A6570]">{status}</p>}
      {error && <p className="text-xs text-[#B02A2A]">{error}</p>}
    </div>
  );
}
```

```bash
#!/usr/bin/env bash
# Four-point verification gate for a generated PDF.
# Usage: bash scripts/verify-pdf.sh <file.pdf> "<expected text fragment>" [expected pages]
set -euo pipefail

PDF="${1:?usage: verify-pdf.sh <file.pdf> <expected-text> [pages]}"
EXPECTED="${2:?expected text fragment required}"
PAGES="${3:-1}"

fail=0

info="$(pdfinfo "$PDF" 2>/dev/null || true)"

if grep -q "Pages:.*$PAGES" <<<"$info"; then
  echo "PASS: page count = $PAGES"
else
  echo "FAIL: page count is not $PAGES"
  echo "$info" | head -5
  fail=1
fi

if grep -q "595.276 x 841.89 pts" <<<"$info"; then
  echo "PASS: A4 geometry"
else
  echo "FAIL: page size is not A4"
  fail=1
fi

if pdftotext "$PDF" - 2>/dev/null | grep -qF "$EXPECTED"; then
  echo "PASS: expected text present"
else
  echo "FAIL: expected text not found: $EXPECTED"
  fail=1
fi

if qpdf --check "$PDF" 2>&1 | grep -q "No syntax or stream encoding errors"; then
  echo "PASS: qpdf structural check"
else
  echo "FAIL: qpdf reported structural errors"
  qpdf --check "$PDF" 2>&1 | head -5
  fail=1
fi

if [ "$fail" -ne 0 ]; then
  echo "VERIFICATION FAILED for $PDF"
  exit 1
fi
echo "VERIFICATION PASSED for $PDF"
```

**Three traps worth stating explicitly, because each one cost real debugging time:**

1. `fromJsx` is exported from `@takumi-rs/helpers/jsx`, not from the package root, and it returns a
   `Promise`. Forgetting `await` throws `Cannot read properties of undefined (reading 'node')`.
2. **Never post a React element through `postMessage`.** A React element carries
   `$$typeof: Symbol.for("react.transitional.element")`, and the structured-clone algorithm cannot
   clone symbols — the message throws `DataCloneError`. pdfcn's own playground sidesteps this by
   sending a *code string* the worker turns into an element. This plan sends a plain JSON *model*
   and lets the worker build the element from the imported document component, which is the same idea
   with a fixed catalogue instead of arbitrary code.
3. The `pdftotext` line `Syntax Error: Suspects object is wrong type (boolean)` appears on **every**
   Takumi output, including `qpdf --check`-clean files. It is a poppler metadata-parsing quirk, not a
   document defect. Use `qpdf --check` as the structural gate and treat that poppler line as noise —
   but keep `pdftotext` for the text-content assertion, which does work.

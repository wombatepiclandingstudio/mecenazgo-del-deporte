# Etiquetas de triage

Las skills hablan en los cinco roles canónicos de triage. Este fichero mapea esos roles a las cadenas de etiqueta reales del tracker de este repo.

| Etiqueta en mattpocock/skills | Etiqueta en nuestro tracker | Significado                                   |
| ------------------------------ | --------------------------- | --------------------------------------------- |
| `needs-triage`                 | `needs-triage`              | El mantenedor tiene que evaluar este issue    |
| `needs-info`                   | `needs-info`                | Se espera más información de quien reporta    |
| `ready-for-agent`              | `ready-for-agent`           | Especificado por completo, listo para un agente |
| `ready-for-human`              | `ready-for-human`           | Requiere implementación humana                |
| `wontfix`                      | `wontfix`                   | No se va a trabajar en ello                   |

Cuando una skill mencione un rol (p. ej. "aplica la etiqueta de triage ready-for-agent"), usa la cadena correspondiente de esta tabla.

Edita la columna "Etiqueta en nuestro tracker" para que coincida con el vocabulario que uses de verdad.
